LIFE QUEST PWA v1.0

1) Estrai tutto lo ZIP sul PC.
2) Nella repository GitHub: Add file > Upload files.
3) Carica index.html, manifest.webmanifest, sw.js e la cartella icons. NON caricare il backup personale.
4) Commit changes.
5) Settings > Pages > Deploy from a branch > main > /(root) > Save.
6) Attendi la pubblicazione; l'indirizzo sarà https://TUO-UTENTE.github.io/life-quest/

I dati sono salvati nel browser del dispositivo (localStorage), non inviati a GitHub. Esporta regolarmente un backup JSON da Dati. Quando passi da file locale al sito online, lo spazio dati del browser è separato: importa il backup se necessario.
